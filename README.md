# صلوات شمار (Salawat Counter)

یک اپلیکیشن مدرن و زیبا برای شمارش صلوات، ساخته شده با **Expo** و **React Native**.

این پروژه برای ارائه دانشگاهی طراحی شده و شامل ویژگی‌های کامل، رابط کاربری جذاب و کد تمیز است.

## ویژگی‌ها

- **شمارشگر اصلی** با انیمیشن روان و دایره پیشرفت
- **لمس کوتاه**: +۱ صلوات
- **لمس طولانی**: +۱۰ صلوات
- **هدف جلسه** قابل تنظیم (۳۳، ۱۰۰، ۳۰۰، ۱۰۰۰ و دلخواه)
- **آمار روزانه و کل**
- **تاریخچه ۳۰ روز اخیر**
- **لرزش (Haptic Feedback)** قابل روشن/خاموش
- **ذخیره‌سازی محلی** با AsyncStorage
- **فونت‌های فارسی و عربی** (Cairo + Amiri)
- **رابط کاربری RTL** و طراحی مدرن اسلامی

## تکنولوژی‌ها

- Expo SDK 54
- React Native + TypeScript
- React Native Reanimated (انیمیشن)
- Expo Haptics
- Expo Linear Gradient
- React Native SVG
- AsyncStorage
- Expo Google Fonts (Cairo & Amiri)

## نحوه اجرا در Expo Go

1. نصب وابستگی‌ها:

```bash
cd salawat-counter
npm install
```

2. اجرای پروژه:

```bash
npx expo start
```

3. اسکن QR Code با اپلیکیشن **Expo Go** روی گوشی (Android یا iOS)

## نکات برای ارائه دانشگاهی

- کد کاملاً TypeScript و خوانا است
- از بهترین روش‌های UI/UX استفاده شده (اندازه تاچ مناسب، بازخورد لمسی، انیمیشن معنادار)
- داده‌ها persist می‌شوند (حتی بعد از بستن اپ)
- پشتیبانی کامل از زبان فارسی و راست‌چین
- طراحی مدرن با الهام از رنگ‌های اسلامی (سبز زمردی + طلایی)
